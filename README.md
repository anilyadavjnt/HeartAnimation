# ❤️ HeartAnimation iOS App

A beautiful Heart Animation iOS application developed using **Swift and UIKit**.

This project demonstrates creative heart animations using UIImageView and UIImage animations to create an attractive visual experience.

## 📱 App Screenshots



## ✨ Features

- Beautiful Heart Animations
- Smooth Animation Effects
- UIImageView Animation
- Multiple Heart Animation Effects
- Clean and Simple UI

## 🛠 Technologies Used

- Swift
- UIKit
- UIImageView
- UIView Animation
- Xcode

## 🚀 Installation

1. Clone this repository.
2. Open the `.xcodeproj` file in Xcode.
3. Select an iOS Simulator.
4. Build and Run the project.
